## How the program works

- `main.ts` (Node 22, standard library only) draws the whole image from the 50 verified stories — masthead, timeline, four illustrated leads, twelve illustrated medium stories, the numbered world map, the 17–50 list and the date-check footer — and encodes it as a PNG with a hand-rolled encoder (no image library, no photographs, no network calls). It writes `entry.png` to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
- Verified: `env -i node main.ts` run twice produces identical SHA-256 hashes (`a4e329708f66bf887ae819a995d749d4fe9cebee2842893ed1a1b939c3169f3a`); the PNG is 51,976 bytes (limit 1 MiB) at exactly 1024×1024.
